                                                      Проект "Калькулятор"
Главная суть проекта - мы можем посчитать __что угодно__. Почему же? У нас есть система команд, которая является __Тьюринг - полной__, то есть любая задача, 
решаемая каким - либо алгоритмом решится и с помощью нашего "калькулятора". Но после такого язык не поворачивается назвать нашу программу калькулятором. Это самая настоящая __вычислительная машина__!

В общем, суть проекта ясна. Перейдем к подробностям.

Программистские фичи и особенности нашей машины:
1) Проект состоит из трех отдельных частей: __процессор__, __ассемблер__, __дизассемблер__
2) В текстовом файле мы пишем программу для вычисления чего-либо с помощью специальных команд. И тут в дело вступает __ассемблер__, которые переводит наши текстовые команды в команды, понятные процессору. В основном, он основан на использовании в большом количестве функции __strcmp()__, которая сравнивает введенную команду с имеющимися. И в итоге ассемблер обрабатывает текстовые команды, переводит их в числовые и записывает в файл(так называемый __байт-код__)
3) Также есть вспомогательная программка __дизассемблер__, которая __байт-код__ переводит обратно в текстовое представление, чтобы мы могли проверить правилльность нашего ассемблирования
4) Теперь у нас есть __байт-код__. Нам нужно его обработать. И тут нам на помощь приходит __виртуальная машина__(в простонародье __процессор__). Она считывает данные из файла с __байт-кодом__ и создает __массив с кодом__, который будет обрабатывать.
5) Теперь о том, как происходит обработка этого массива. Процессор идет по командам. По ее номеру он понимает, что это за команда и начинает ее выполнение. После выполнения ему нужно сместиться в нашем массиве. И его смещение зависит от того, сколько дополнительных аргументов имела эта команда. И так выполняется каждая команда друг за другом.
6) Процессор основан на __стеке__, который хранит данные для вычислений. Также наш процессор имеет 4 __регистра__(переменные, которые помогают нам хранить данные)
7) У нас имеется система меток, на которые мы можем перемещаться с помощью либо условных, либо безусловных команд(__JMP__ и подобные)
8) Также имеются функции(по сути это метки, которые запоминают место, откуда мы прыгнули). Функция вызывается командой __CALL__. Возврат обратно происходит с помощью команды __RET__. У нас может накопиться несколько возвратов. Порядок возвратов мы храним в специальном стеке возвратов
9) Также процессор имеет оперативную память __RAM__, которая представляет собой просто массив данных. С помощью оперативной памяти создана программка для рисования кружочка в консоли
10)Создан __dump__ процессора для упрощения дебага программ
11) И с помощью своих команд написаны программы: __1)решение квадратного уравнения 2)подсчет факториала числа с помощью рекурсии 3)рисование кружка в консоли с помощью оперативной памяти__ 

Теперь поговорим о командах:
1) Команда __PUSH__, которая пушит элемент в стек. В качестве аргументы принимает число
2) Команды __POPR__ и __PSHR__. Первая забирает элемент из стека и кладет в регистр. Вторая пушит значение регистра в стек. Принимают в качестве аргумента имя регистра (__AX__, __BX__, __CX__, __DX__)
3) Большое количество арифметических операций
4) Команда __OUT__, которая выводит в консоль значение последнего элемента стека
5) Команда __HLT__, завершающая выполнение программы
6) Команда __IN__, которая пушит в стек введенное с клавиатуры число
7) Система меток и прыжков
